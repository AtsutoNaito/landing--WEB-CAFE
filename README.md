# WEB CAFE（学習制作）

このサイトは、書籍「1冊ですべて身につくHTML&CSSとWebデザイン」の課題をベースに作成した、架空のカフェWEBサイトです。  
HTML / CSS の基本構造や、レイアウト設計の理解を目的とした学習用制作物です。

## 制作目的

- HTMLとCSSの基礎構造理解
- 課題通りのUI再現を通した基礎スキルの定着
- Webサイトの全体フロー（HTMLマークアップ → CSSレイアウト → 公開まで）の一連の流れを経験する

## 得られた学び / 成長ポイント

- 2カラムレイアウトの幅調整で詰まったが、`width: % 指定` によって柔軟な調整ができる理解につながった
- デザイン再現によって、余白 / 見出し階層 / タイポグラフィの見せ方の重要性を体感した
- GitHubページでの公開までの流れを習得
